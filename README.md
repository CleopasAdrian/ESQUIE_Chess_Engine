# ESQUIE Chess Engine

ESQUIE is a chess engine in development as a personal project. It uses the Universal Chess Interface (UCI) communication protocol,is written in C++, and is named after the most powerful character in the game Clair Obscur: Expedition 33 by Sandfall Interactive. After all, I want my engine to the be the strongest in the world! (lol to that last point; I am an intermdediate programmer.)

Here is a roadmap of the classic features found in other top engines that I aim to implement in ESQUIE, in rough order of priority:

- [x] Board representation  
- [x] Move generation
- [x] Minimax algorithm   
- [ ] Alpha-beta pruning
- [ ] Quiessence search
- [ ] Time management
- [ ] Piece-square tables
- [ ] Move ordering
- [ ] Iteratvie deepening
